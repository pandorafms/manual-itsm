    Glossaire des termes¶

    Ce glossaire rassemble les termes que Pandora ITSM utilise avec un sens propre. Il ne remplace pas les chapitres fonctionnels : il fixe le vocabulaire pour que deux personnes n'appellent pas « utilisateur » des choses différentes. Chaque bloc renvoie au chapitre où le concept est développé.

    Produit et cycle de version¶

    Terme Définition
    Pandora ITSM / PITSM Produit de gestion des services IT de Pandora FMS. « Pandora ITSM » est la marque ; « PITSM » est l'abréviation utilisée après la première mention.
    Pandora FMS / PFMS Produit de supervision de Pandora FMS. Il s'intègre à Pandora ITSM pour l'authentification, l'inventaire et les tickets, mais ce n'est pas le même produit.
    Pandora RC Produit de contrôle à distance de Pandora. Il s'intègre à Pandora ITSM pour gérer les équipements.
    Warp Update Programme de mise à jour de Pandora ITSM. Il gère les mises à jour en ligne et hors ligne, les options et le journal.
    OUM / MR / LTS / FR OUM est l'Offline Update Manager, le paquet de mise à jour hors ligne. MR est le Minor Release ou niveau de migration de la base. LTS est une version de support à long terme. FR est une Feature Release avec de nouvelles fonctionnalités.
    Patch Correction ponctuelle sur une version. Elle ne change pas le cycle de support à elle seule.
    Licence perpétuelle / abonnement La licence perpétuelle s'achète une fois ; l'abonnement se renouvelle par période. Les deux peuvent limiter le nombre d'administrateurs.
    Manager Count / Manager Limit Termes de licence : nombre d'administrateurs utilisés et limite autorisée.

    Utilisateurs, permissions et organisation¶

    Terme Définition
    Utilisateur groupé / autonome L'utilisateur groupé appartient à un groupe et partage la visibilité avec ses collègues ; l'autonome ne voit que son propre contenu.
    Contact / entreprise Le contact est une personne du CRM sans accès à l'application ; l'entreprise est l'entité qui regroupe contacts, contrats, factures et tickets.
    Groupe / profil / rôle Le groupe contrôle la visibilité ; le profil accorde les permissions ; le rôle précise les fonctions dans un projet ou une entreprise. Ils ne sont pas interchangeables.
    User mode / ACL / bit de permission Le User mode est le mode d'un utilisateur sur un groupe ; l'ACL est la liste de contrôle d'accès résultante ; le bit de permission est chaque permission concrète du profil.
    Superadmin / administrateur / Manager Le superadmin est le superutilisateur et s'authentifie toujours localement ; l'administrateur a le profil Administration ; le Manager est responsable d'une entreprise du CRM.
    HR / UM / VCM Permissions des personnes : HR pour les ressources humaines, UM pour la gestion des utilisateurs et VCM pour la gestion des congés.
    CR / CW / CM Permissions CRM : lire, écrire et gérer.
    CIR / CIW / CIM Permissions de factures : lire, écrire et gérer.
    RR / RM Permissions de rapports : lire et gérer.
    KW / KM Permissions de base de connaissance : écrire et gérer.
    WR / WW / WM Permissions du Wiki : lire, écrire et administrer.
    PR / IR / VR / AR / WOR Bits de visibilité des projets, tickets, inventaire, agenda et ordres de travail.

    Tickets et support¶

    Terme Définition
    Ticket / incident Le ticket est l'objet ouvert, affecté et fermé dans la console. « Incident » est un concept général, pas un synonyme de l'objet.
    Créateur / éditeur / propriétaire Le créateur décrit le problème ; l'éditeur saisit le ticket ; le propriétaire est chargé de le résoudre.
    Contributeur / utilisateur associé Le contributeur apporte des informations sans être créateur ni propriétaire ; l'utilisateur associé a participé et reçoit les notifications.
    Équipe de support / Round Robin / Load Balanced / fallback L'équipe regroupe des agents ; Round Robin tourne ; Load Balanced affecte le moins chargé ; le fallback reçoit le ticket si personne n'est disponible.
    État / mappage des états L'état est la phase du ticket ; le mappage définit les transitions autorisées.
    Résolution / épilogue La résolution est le résultat ; l'épilogue explique ce qui a été fait à la clôture.
    Priorité / criticité La priorité ordonne le travail ; la criticité mesure l'impact. Elles ne coïncident pas toujours.
    SLA / FRT / TTR / escalade Le SLA est l'accord de niveau de service ; FRT est le temps de première réponse ; TTR est le temps de résolution ; l'escalade change propriétaire, groupe ou priorité.
    Workflow / règle / condition / action / macro Le workflow automatise les tickets ; la règle contient conditions et actions ; la macro remplace des données du ticket. Ne pas confondre avec le workflow CRM.
    Unité de travail / note interne / note privée L'unité de travail enregistre temps et détail ; la note interne est masquée au créateur ; la note privée n'est visible que par les administrateurs et son auteur.
    Ordre de travail Document PDF généré depuis un modèle avec les données du ticket, comme un bon de livraison ou une preuve d'exécution.
    Type de ticket / champ personnalisé / combo / linked Le type regroupe des champs ; le champ personnalisé ajoute des données ; combo est une liste d'options ; linked enchaîne un champ parent et un champ enfant.
    Q/A / enquête / satisfaction L'assurance qualité évalue la clôture ; l'enquête développe une évaluation négative ; la satisfaction est l'avis du client.

    Courriel¶

    Terme Définition
    SMTP / POP / IMAP Protocoles d'envoi (SMTP) et de réception (POP ou IMAP).
    OAuth 2.0 / Client ID / Tenant ID / Client Secret / Redirect URI Authentification déléguée pour Microsoft 365 : identifiants de l'application, secret et URL de retour.
    File de courriels / Email destination / Email origin La file contient les messages en attente ; Email destination identifie la boîte qui crée les tickets ; Email origin filtre les expéditeurs valides.
    Message delimiter / masking / blacklist Le délimiteur coupe le fil ; le masquage cache les adresses ; la liste noire écarte expéditeurs ou domaines.
    Microsoft 365 / Google Workspace Services de messagerie professionnelle pris en charge par l'intégration.
    PostMark / SPF / DKIM PostMark est un serveur d'envoi ; SPF et DKIM sont des enregistrements DNS qui améliorent la délivrabilité.
    Rebond Courriel qui n'a pas pu être délivré. Il est mesuré dans les campagnes.

    Connaissance, Wiki et téléchargements¶

    Terme Définition
    Base de connaissance (KB) / article / catégorie / type de produit La base de connaissance stocke des solutions dans des articles classés par catégorie et produit.
    Wiki / ACL de page / side_menu / TOC Le Wiki est la documentation interne ; l'ACL de page contrôle lecture et écriture ; side_menu est le menu latéral ; TOC est la table des matières.
    Téléchargement / release / dossier / catégorie de téléchargement / fichier interne ou privé Les téléchargements distribuent fichiers et releases dans des dossiers et catégories ; un fichier interne ou privé a une visibilité limitée.

    Inventaire¶

    Terme Définition
    Inventaire / CMDB L'inventaire est la base des actifs ; la CMDB est la base de données de gestion de configuration.
    Objet / type d'objet L'objet est une instance concrète ; le type définit ses champs et son comportement.
    Champ personnalisé / champ externe Le champ personnalisé est défini par l'organisation ; le champ externe est rempli depuis une autre source.
    Relation / vue arborescente / stock / état / étiquette La relation relie des objets ; la vue arborescente montre la hiérarchie ; le stock contrôle les quantités ; l'état et l'étiquette classent.
    Inventaire distant / agent / module / nœud L'inventaire distant est synchronisé depuis Pandora FMS ; l'agent envoie les données ; le module est un contrôle ; le nœud est le serveur de supervision.

    Projets et temps¶

    Terme Définition
    Projet / tâche / sous-tâche Le projet regroupe le travail ; la tâche est une unité planifiable ; la sous-tâche dépend d'une autre tâche.
    Jalon / Gantt / tableau Le jalon est une date de durée nulle ; le Gantt montre la planification ; le tableau organise les tâches par état.
    Dépendance start-to-start / finish-to-start / finish-to-finish Règles qui empêchent une tâche de commencer ou finir avant une autre.
    Imputation / coût / rentabilité / écart L'imputation enregistre les heures ; le coût les valorise ; la rentabilité compare revenus et coûts ; l'écart mesure la différence avec le plan.
    Timetracker / pointage / pause / journée Le Timetracker enregistre l'activité ; le pointage marque début et fin ; la pause interrompt la journée ; la journée est le temps prévu.
    Congés / absence / télétravail Absences et mode de travail qui affectent la disponibilité et les rapports.
    Forfait d'heures Heures contractées ou budgétées pour un projet, avec consommation et solde restant.

    CRM et marketing¶

    Terme Définition
    Contrat / type de contrat / modèle de contrat Le contrat couvre un service ; le type définit les champs ; le modèle génère le PDF avec des macros.
    Facture reçue / émise Received est une facture reçue ; Submitted est une facture émise. L'émise est verrouillée et génère un PDF.
    Quote / devis Proposition commerciale formelle liée à un deal ou à un contact.
    Deal / opportunité / pipeline / étape Le deal est une opportunité de vente ; le pipeline est l'entonnoir ; l'étape est la phase dans l'entonnoir.
    Deal registration Enregistrement d'opportunités par des partenaires ou revendeurs, séparé du pipeline principal.
    Campagne / template / liste statique / liste dynamique La campagne envoie un message ; le template est le design ; la liste statique est fixe ; la liste dynamique est recalculée à l'envoi.
    Formulaire Formulaire web qui capture des contacts et les crée ou met à jour dans le CRM.
    Étiquette / tag Marque transversale pour classer et filtrer ; elle n'accorde pas de permissions.
    Consentement Autorisation du contact pour recevoir des communications ou accepter une politique.
    Entreprise parente / rôle d'entreprise / service IT L'entreprise parente organise la hiérarchie ; le rôle classe l'entreprise ; le service IT classe les tickets.

    Changements¶

    Terme Définition
    Changement / demande de changement Le changement est une modification contrôlée ; la demande est son point d'entrée.
    Autorisation / planification / tâche de changement L'autorisation approuve ; la planification organise ; la tâche de changement exécute le travail.
    Revue / clôture La revue vérifie le résultat ; la clôture termine le cycle.
    Risque / impact Le risque est la probabilité d'un effet négatif ; l'impact est son étendue.
    Approbateur / équipe de changement Personnes et équipes qui autorisent et exécutent le changement.

    API et intégrations¶

    Terme Définition
    API v1 / API v2 Interfaces de programmation de Pandora ITSM. v2 est l'API actuelle ; v1 est l'ancienne.
    Token / endpoint Le token authentifie la requête ; l'endpoint est l'URL concrète de la ressource.
    JSON / OpenAPI / pagination JSON est le format de données ; OpenAPI décrit l'API ; la pagination découpe les résultats longs.
    Webhook / rate limit Le webhook notifie des événements ; le rate limit limite les requêtes par période.
    ChatBot / IA / prompt / canal Le ChatBot gère les conversations ; l'IA génère les réponses ; le prompt est l'instruction ; le canal est le moyen de contact.
    GitLab Plateforme de dépôts intégrée pour consulter les tickets d'un projet.

    Administration et sécurité¶

    Terme Définition
    Setup / token Setup est la configuration ; un token est chaque paramètre qui y est stocké.
    Visibilité Niveau Hidden ou Full d'une section pour un groupe.
    2FA / TOTP Second facteur d'authentification basé sur des codes temporaires.
    Session / timeout Période entre la connexion et son expiration par inactivité.
    HTTPS / SSL/TLS / certificat / CA HTTPS chiffre la connexion ; SSL/TLS est le protocole ; le certificat identifie le serveur ; la CA le valide.
    FQDN / IP / port Nom complet, adresse réseau et port de connexion.
    Backup / restore Sauvegarde et restauration de la base et des pièces jointes.
    Cron Tâche périodique du système qui exécute des processus automatiques.
    Audit / log / événement L'audit enregistre les actions utilisateur ; le log stocke les erreurs ; l'événement enregistre l'activité système.
    Diagnostic / DB Manager Le diagnostic montre l'état du système ; DB Manager exécute du SQL avec des permissions élevées.

    Termes techniques et formats¶

    Terme Définition
    CSV / PDF / JSON / XML / SQL Formats d'échange, de rapport, de données et de requête utilisés par l'application.
    HTML / URL / URI Langage de balisage, localisateur et identifiant de ressource.
    PHP-FPM / Apache / MySQL / Percona Composants courants du serveur web et de la base de données.
    EL9 / EL10 / Ubuntu Systèmes d'exploitation pris en charge pour l'installation.
    MB / GB Unités de taille de fichier et de stockage.

    Termes ambigus¶

    Forme problématique Forme recommandée
    company / « compañía » entreprise
    workunit unité de travail (l'identifiant workunit se cite comme code)
    KB base de connaissance
    ticket / incident ticket pour l'objet ; « incident » comme concept général
    utilisateur / contact utilisateur avec accès ; contact sans accès
    profil / rôle profil accorde les permissions ; rôle précise les fonctions
    groupe / équipe groupe contrôle la visibilité ; équipe répartit les tickets
    console interface
    SLA / ANS SLA, développé à la première mention
    PandoraFMS Pandora FMS
    Office 365 Microsoft 365
    LTS / FR / OUM / MR Développer chaque sigle à sa première mention
