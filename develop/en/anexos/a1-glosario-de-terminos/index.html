    Glossary of terms¶

    This glossary gathers the terms Pandora ITSM uses with a meaning of their own. It does not replace the functional chapters: it fixes the vocabulary so two people do not call different things "user". Each block links to the chapter where the concept is developed.

    Product and release cycle¶

    Term Definition
    Pandora ITSM / PITSM Pandora FMS's IT service management product. "Pandora ITSM" is the brand; "PITSM" is the abbreviation used after the first mention.
    Pandora FMS / PFMS Pandora FMS monitoring product. It integrates with Pandora ITSM for authentication, inventory and tickets, but it is not the same product.
    Pandora RC Pandora remote control product. It integrates with Pandora ITSM to manage devices.
    Warp Update Pandora ITSM updater. It supports online and offline updates, options and journal review.
    OUM / MR / LTS / FR OUM is the Offline Update Manager, the offline update package. MR is the Minor Release or database migration level. LTS is a long-term support release. FR is a Feature Release with new features.
    Patch Point fix on a release. It does not change the support cycle by itself.
    Perpetual licence / subscription A perpetual licence is bought once; a subscription is renewed per period. Both may limit the number of administrators.
    Manager Count / Manager Limit Licence terms: number of administrators used and the allowed limit.

    Users, permissions and organisation¶

    Term Definition
    Grouped / standalone user A grouped user belongs to a group and shares visibility with colleagues; a standalone user only sees their own content.
    Contact / company A contact is a CRM person without application access; a company is the entity that groups contacts, contracts, invoices and tickets.
    Group / profile / role The group controls visibility; the profile grants permissions; the role refines functions within a project or company. They are not interchangeable.
    User mode / ACL / permission bit User mode is a user's mode over a group; the ACL is the resulting access control list; the permission bit is each concrete profile permission.
    Superadmin / administrator / Manager A superadmin is the superuser and always authenticates locally; an administrator has the Administration profile; a Manager is responsible for a CRM company.
    HR / UM / VCM People permissions: HR for human resources, UM for user management and VCM for vacation management.
    CR / CW / CM CRM permissions: read, write and manage.
    CIR / CIW / CIM Invoice permissions: read, write and manage.
    RR / RM Report permissions: read and manage.
    KW / KM Knowledge base permissions: write and manage.
    WR / WW / WM Wiki permissions: read, write and administer.
    PR / IR / VR / AR / WOR Visibility bits for projects, tickets, inventory, calendar and work orders.

    Tickets and support¶

    Term Definition
    Ticket / incident A ticket is the object opened, assigned and closed in the console. "Incident" is a general concept, not a synonym for the object.
    Creator / editor / owner The creator describes the problem; the editor enters the ticket; the owner is responsible for solving it.
    Contributor / associated user A contributor provides information without being creator or owner; an associated user has taken part and receives notifications.
    Support team / Round Robin / Load Balanced / fallback The team groups agents; Round Robin rotates; Load Balanced assigns the least loaded; fallback receives the ticket if nobody is available.
    Status / status mapping The status is the ticket phase; the mapping defines which transitions are allowed.
    Resolution / epilogue The resolution is the outcome; the epilogue explains what was done on closure.
    Priority / criticality Priority orders work; criticality measures impact. They do not always match.
    SLA / FRT / TTR / escalation SLA is the service level agreement; FRT is first response time; TTR is resolution time; escalation changes owner, group or priority.
    Workflow / rule / condition / action / macro A workflow automates tickets; the rule contains conditions and actions; the macro replaces ticket data. Do not confuse it with the CRM workflow.
    Work unit / internal note / private note A work unit records time and detail; an internal note is hidden from the creator; a private note is visible only to administrators and its author.
    Work order PDF document generated from a template with ticket data, as a delivery note or proof of work.
    Ticket type / custom field / combo / linked The type groups fields; a custom field adds data; combo is an option list; linked chains a parent and child field.
    Q/A / survey / satisfaction Quality assurance rates closure; the survey expands a negative rating; satisfaction is the customer's opinion.

    Email¶

    Term Definition
    SMTP / POP / IMAP Sending (SMTP) and receiving (POP or IMAP) protocols.
    OAuth 2.0 / Client ID / Tenant ID / Client Secret / Redirect URI Delegated authentication for Microsoft 365: application identifiers, secret and return URL.
    Mail queue / Email destination / Email origin The queue holds pending messages; Email destination identifies the mailbox that creates tickets; Email origin filters valid senders.
    Message delimiter / masking / blacklist The delimiter cuts the thread; masking hides addresses; the blacklist discards senders or domains.
    Microsoft 365 / Google Workspace Corporate email services supported by the integration.
    PostMark / SPF / DKIM PostMark is a sending server; SPF and DKIM are DNS records that improve deliverability.
    Bounce Email that could not be delivered. It is measured in campaigns.

    Knowledge, Wiki and downloads¶

    Term Definition
    Knowledge base (KB) / article / category / product type The knowledge base stores solutions in articles classified by category and product.
    Wiki / page ACL / side_menu / TOC The Wiki is internal documentation; the page ACL controls read and write; side_menu is the side menu; TOC is the table of contents.
    Download / release / folder / download category / internal or private file Downloads distribute files and releases in folders and categories; an internal or private file has limited visibility.

    Inventory¶

    Term Definition
    Inventory / CMDB Inventory is the asset base; CMDB is the configuration management database.
    Object / object type The object is a concrete instance; the type defines its fields and behaviour.
    Custom field / external field A custom field is defined by the organisation; an external field is filled from another source.
    Relationship / tree view / stock / status / tag A relationship links objects; the tree view shows hierarchy; stock controls quantity; status and tag classify.
    Remote inventory / agent / module / node Remote inventory is synchronised from Pandora FMS; the agent sends data; the module is a check; the node is the monitoring server.

    Projects and time¶

    Term Definition
    Project / task / subtask The project groups work; the task is a planable unit; the subtask hangs from another task.
    Milestone / Gantt / board A milestone is a zero-duration date; the Gantt shows time planning; the board organises tasks by status.
    Start-to-start / finish-to-start / finish-to-finish dependency Rules that prevent one task from starting or finishing before another.
    Time booking / cost / profitability / deviation Time booking records hours; cost values them; profitability compares revenue and cost; deviation measures the gap from plan.
    Timetracker / clock-in / pause / shift Timetracker records activity; clock-in marks start and end; a pause interrupts the shift; the shift is planned time.
    Vacation / leave / remote work Absences and work mode that affect availability and reports.
    Hour bucket Contracted or budgeted hours for a project, with consumption and remaining balance.

    CRM and marketing¶

    Term Definition
    Contract / contract type / contract template The contract covers a service; the type defines fields; the template generates the PDF with macros.
    Received / submitted invoice Received is an incoming invoice; Submitted is an issued invoice. The issued one is locked and generates a PDF.
    Quote Formal commercial proposal linked to a deal or contact.
    Deal / opportunity / pipeline / stage A deal is a sales opportunity; the pipeline is the funnel; the stage is the phase inside the funnel.
    Deal registration Opportunity registration by partners or resellers, separate from the main pipeline.
    Campaign / template / static list / dynamic list The campaign sends a message; the template is the design; the static list is fixed; the dynamic list is recalculated at send time.
    Form Web form that captures contacts and creates or updates them in the CRM.
    Tag Cross-cutting mark for classification and filtering; it does not grant permissions.
    Consent The contact's authorisation to receive communications or accept a policy.
    Parent company / company role / IT service The parent company organises hierarchy; the role classifies the company; the IT service classifies tickets.

    Changes¶

    Term Definition
    Change / change request A change is a controlled modification; the request is its entry point.
    Authorisation / planning / change task Authorisation approves; planning organises; the change task executes the work.
    Review / closure Review checks the result; closure ends the cycle.
    Risk / impact Risk is the probability of a negative effect; impact is its scope.
    Approver / change team People and teams that authorise and execute the change.

    API and integrations¶

    Term Definition
    API v1 / API v2 Pandora ITSM programming interfaces. v2 is the current API; v1 is the legacy one.
    Token / endpoint The token authenticates the request; the endpoint is the concrete resource URL.
    JSON / OpenAPI / pagination JSON is the data format; OpenAPI describes the API; pagination splits long results.
    Webhook / rate limit A webhook notifies events; a rate limit caps requests per period.
    ChatBot / AI / prompt / channel The ChatBot handles conversations; AI generates answers; the prompt is the instruction; the channel is the contact medium.
    GitLab Repository platform integrated to read project tickets.

    Administration and security¶

    Term Definition
    Setup / token Setup is configuration; a token is each parameter stored in it.
    Visibility Hidden or Full level of a section for a group.
    2FA / TOTP Second authentication factor based on temporary codes.
    Session / timeout Period from login until it expires through inactivity.
    HTTPS / SSL/TLS / certificate / CA HTTPS encrypts the connection; SSL/TLS is the protocol; the certificate identifies the server; the CA validates it.
    FQDN / IP / port Full name, network address and connection port.
    Backup / restore Backup and restoration of database and attachments.
    Cron Periodic system task that runs automatic processes.
    Audit / log / event Audit records user actions; the log stores errors; the event records system activity.
    Diagnostics / DB Manager Diagnostics shows system status; DB Manager runs SQL with elevated permissions.

    Technical terms and formats¶

    Term Definition
    CSV / PDF / JSON / XML / SQL Exchange, report, data and query formats used by the application.
    HTML / URL / URI Markup language, resource locator and resource identifier.
    PHP-FPM / Apache / MySQL / Percona Common web server and database components.
    EL9 / EL10 / Ubuntu Supported operating systems for installation.
    MB / GB File and storage size units.

    user / contact user with access; contact without access
    profile / role profile grants permissions; role refines functions
    group / team group controls visibility; team distributes tickets
    console interface
    SLA / ANS SLA, expanded on first mention
    PandoraFMS Pandora FMS
    Office 365 Microsoft 365
