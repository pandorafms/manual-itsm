    Glosario de términos¶

    Este glosario reúne los términos que Pandora ITSM usa con un significado propio. No sustituye a los capítulos funcionales: fija el vocabulario para que dos personas no llamen «usuario» a cosas distintas. Cada bloque enlaza al capítulo donde se desarrolla el concepto.

    Producto y ciclo de vida¶

    Término Definición
    Pandora ITSM / PITSM Producto de gestión de servicios IT de Pandora FMS. «Pandora ITSM» es la marca; «PITSM» es la abreviatura que se usa después de la primera mención.
    Pandora FMS / PFMS Producto de monitorización de Pandora FMS. Se integra con Pandora ITSM para autenticación, inventario y tickets, pero no es el mismo producto.
    Pandora RC Producto de control remoto de Pandora. Se integra con Pandora ITSM para gestionar equipos.
    Warp Update Actualizador de Pandora ITSM. Permite actualizar online u offline, revisar opciones y consultar el journal.
    OUM / MR / LTS / FR OUM es el Offline Update Manager, el paquete de actualización offline. MR es el Minor Release o nivel de migración de base de datos. LTS es una versión de soporte a largo plazo. FR es una Feature Release con funcionalidades nuevas.
    Parche Corrección puntual sobre una versión. No cambia el ciclo de soporte por sí mismo.
    Licencia perpetua / suscripción La licencia perpetua se adquiere una vez; la suscripción se renueva por periodo. Ambas pueden limitar el número de administradores.
    Manager Count / Manager Limit Términos de licencia: número de administradores usados y límite permitido.

    Usuarios, permisos y organización¶

    Término Definición
    Usuario agrupado / independiente El agrupado pertenece a un grupo y comparte visibilidad con sus compañeros; el independiente solo ve su propio contenido.
    Contacto / empresa El contacto es una persona del CRM sin acceso a la aplicación; la empresa es la entidad que agrupa contactos, contratos, facturas y tickets.
    Grupo / perfil / rol El grupo controla la visibilidad; el perfil concede permisos; el rol matiza funciones dentro de un proyecto o empresa. No son intercambiables.
    User mode / ACL / bit de permiso El User mode es el modo de un usuario sobre un grupo; la ACL es la lista de control de acceso resultante; el bit de permiso es cada permiso concreto del perfil.
    Superadmin / administrador / Manager El superadmin es el superusuario y siempre se autentica localmente; el administrador tiene perfil Administration; el Manager es el responsable de una empresa del CRM.
    HR / UM / VCM Permisos de personas: HR para recursos humanos, UM para gestión de usuarios y VCM para gestionar vacaciones.
    CR / CW / CM Permisos de CRM: leer, escribir y gestionar.
    CIR / CIW / CIM Permisos de facturas: leer, escribir y gestionar.
    RR / RM Permisos de informes: leer y gestionar.
    KW / KM Permisos de base de conocimiento: escribir y gestionar.
    WR / WW / WM Permisos de Wiki: leer, escribir y administrar.
    PR / IR / VR / AR / WOR Bits de visibilidad de proyectos, tickets, inventario, agenda y partes de trabajo.

    Tickets y soporte¶

    Término Definición
    Ticket / incidencia El ticket es el objeto que se abre, asigna y cierra en la consola. «Incidencia» se usa como concepto general, no como sinónimo del objeto.
    Creador / editor / propietario El creador describe el problema; el editor introduce el ticket; el propietario se encarga de resolverlo.
    Colaborador / usuario asociado El colaborador aporta información sin ser creador ni propietario; el usuario asociado ha participado y recibe notificaciones.
    Equipo de soporte / Round Robin / Load Balanced / fallback El equipo agrupa agentes; Round Robin reparte por turnos; Load Balanced asigna al de menos carga; el fallback recibe el ticket si nadie está disponible.
    Estado / mapeo de estados El estado indica la fase del ticket; el mapeo define qué transiciones están permitidas.
    Resolución / epílogo La resolución es el resultado; el epílogo explica qué se hizo al cerrar.
    Prioridad / criticidad La prioridad ordena el trabajo; la criticidad mide el impacto. No siempre coinciden.
    SLA / FRT / TTR / escalado El SLA es el acuerdo de nivel de servicio; FRT es el tiempo de primera respuesta; TTR es el tiempo de resolución; el escalado cambia propietario, grupo o prioridad.
    Workflow / regla / condición / acción / macro El workflow automatiza tickets; la regla contiene condiciones y acciones; la macro sustituye datos del ticket. No confundir con el workflow de CRM.
    Unidad de trabajo / nota interna / nota privada La unidad de trabajo registra tiempo y detalle; la nota interna no la ve el creador; la privada solo la ven administradores y su autor.
    Parte de trabajo Documento PDF generado desde una plantilla con datos del ticket, a modo de albarán o prueba de ejecución.
    Tipo de ticket / campo personalizado / combo / linked El tipo agrupa campos; el campo personalizado añade datos; combo es una lista de opciones; linked encadena un campo padre y uno hijo.
    Q/A / encuesta / satisfacción El aseguramiento de calidad valora el cierre; la encuesta amplía la valoración negativa; la satisfacción es la opinión del cliente.

    Correo¶

    Término Definición
    SMTP / POP / IMAP Protocolos de envío (SMTP) y recepción (POP o IMAP) de correo.
    OAuth 2.0 / Client ID / Tenant ID / Client Secret / Redirect URI Autenticación delegada para Microsoft 365: identificadores de la aplicación, secreto y URL de retorno.
    Cola de correo / Email destination / Email origin La cola contiene mensajes pendientes; Email destination identifica el buzón que crea tickets; Email origin filtra los remitentes válidos.
    Message delimiter / masking / blacklist El delimitador corta el hilo; el enmascarado oculta direcciones; la lista negra descarta remitentes o dominios.
    Microsoft 365 / Google Workspace Servicios de correo corporativo compatibles con la integración.
    PostMark / SPF / DKIM PostMark es un servidor de envío; SPF y DKIM son registros DNS que mejoran la entregabilidad.
    Rebote Correo que no se ha podido entregar. Se mide en las campañas.

    Conocimiento, Wiki y descargas¶

    Término Definición
    Base de conocimiento (KB) / artículo / categoría / tipo de producto La base de conocimiento guarda soluciones en artículos clasificados por categoría y producto.
    Wiki / ACL de página / side_menu / TOC La Wiki es documentación interna; el ACL de página controla lectura y escritura; side_menu es el menú lateral; TOC es la tabla de contenido.
    Descarga / release / carpeta / categoría de descarga / fichero interno o privado Las descargas distribuyen ficheros y releases en carpetas y categorías; el fichero interno o privado tiene visibilidad limitada.

    Inventario¶

    Término Definición
    Inventario / CMDB El inventario es la base de activos; la CMDB es la base de datos de gestión de configuración.
    Objeto / tipo de objeto El objeto es una instancia concreta; el tipo define sus campos y comportamiento.
    Campo personalizado / campo externo El campo personalizado lo define la organización; el externo se rellena con datos de otra fuente.
    Relación / vista árbol / stock / estado / etiqueta La relación vincula objetos; la vista árbol muestra jerarquía; el stock controla existencias; el estado y la etiqueta clasifican.
    Inventario remoto / agente / módulo / nodo El inventario remoto se sincroniza desde Pandora FMS; el agente envía datos; el módulo es una comprobación; el nodo es el servidor de monitorización.

    Proyectos y tiempo¶

    Término Definición
    Proyecto / tarea / subtarea El proyecto agrupa trabajo; la tarea es una unidad planificable; la subtarea cuelga de otra tarea.
    Hito / Gantt / tablero El hito es una fecha de duración cero; el Gantt muestra la planificación temporal; el tablero organiza tareas por estado.
    Dependencia start-to-start / finish-to-start / finish-to-finish Reglas que impiden que una tarea empiece o termine antes que otra.
    Imputación / coste / rentabilidad / desviación La imputación registra horas; el coste las valora; la rentabilidad compara ingresos y costes; la desviación mide la diferencia con el plan.
    Timetracker / fichaje / pausa / jornada El Timetracker registra actividad; el fichaje marca entrada y salida; la pausa interrumpe la jornada; la jornada es el tiempo previsto.
    Vacaciones / baja / teletrabajo Ausencias y modalidad de trabajo que afectan a la disponibilidad y a los informes.
    Bolsa de horas Horas contratadas o presupuestadas para un proyecto, con consumo y saldo restante.

    CRM y marketing¶

    Término Definición
    Contrato / tipo de contrato / plantilla de contrato El contrato cubre un servicio; el tipo define campos; la plantilla genera el PDF con macros.
    Factura recibida / emitida Received es una factura recibida; Submitted es una factura emitida. La emitida se bloquea y genera PDF.
    Quote / presupuesto Propuesta económica formal vinculada a un deal o contacto.
    Deal / oportunidad / pipeline / etapa El deal es una oportunidad de venta; el pipeline es el embudo; la etapa es la fase dentro del embudo.
    Deal registration Registro de oportunidades por partners o resellers, separado del pipeline principal.
    Campaña / template / lista estática / lista dinámica La campaña envía un mensaje; la template es el diseño; la lista estática es fija; la dinámica se recalcula al enviar.
    Formulario Formulario web que capta contactos y los registra o actualiza en el CRM.
    Etiqueta / tag Marca transversal para clasificar y filtrar; no concede permisos.
    Consentimiento Autorización del contacto para recibir comunicaciones o aceptar una política.
    Empresa padre / rol de empresa / servicio IT La empresa padre organiza la jerarquía; el rol clasifica la empresa; el servicio IT clasifica los tickets.

    Cambios¶

    Término Definición
    Cambio / solicitud de cambio El cambio es una modificación controlada; la solicitud es su punto de entrada.
    Autorización / planificación / tarea de cambio La autorización aprueba; la planificación organiza; la tarea de cambio ejecuta el trabajo.
    Revisión / cierre La revisión comprueba el resultado; el cierre termina el ciclo.
    Riesgo / impacto El riesgo es la probabilidad de un efecto negativo; el impacto es su alcance.
    Aprobador / equipo de cambio Personas y equipos que autorizan y ejecutan el cambio.

    API e integraciones¶

    Término Definición
    API v1 / API v2 Interfaces de programación de Pandora ITSM. v2 es la API actual; v1 es la heredada.
    Token / endpoint El token autentica la petición; el endpoint es la URL concreta del recurso.
    JSON / OpenAPI / paginación JSON es el formato de datos; OpenAPI describe la API; la paginación divide resultados largos.
    Webhook / rate limit El webhook notifica eventos; el rate limit limita peticiones por periodo.
    ChatBot / IA / prompt / canal El ChatBot atiende conversaciones; la IA genera respuestas; el prompt es la instrucción; el canal es el medio de contacto.
    GitLab Plataforma de repositorios que se integra para consultar tickets de un proyecto.

    Administración y seguridad¶

    Término Definición
    Setup / token Setup es la configuración; el token es cada parámetro que se guarda en ella.
    Visibilidad Nivel Oculto o Completo de una sección para un grupo.
    2FA / TOTP Segundo factor de autenticación basado en códigos temporales.
    Sesión / timeout Periodo desde el inicio de sesión hasta que caduca por inactividad.
    HTTPS / SSL/TLS / certificado / CA HTTPS cifra la conexión; SSL/TLS es el protocolo; el certificado identifica al servidor; la CA lo valida.
    FQDN / IP / puerto Nombre completo, dirección de red y puerto de conexión.
    Backup / restore Copia de seguridad y restauración de base de datos y adjuntos.
    Cron Tarea periódica del sistema que ejecuta procesos automáticos.
    Auditoría / log / evento La auditoría registra acciones de usuario; el log guarda errores; el evento registra actividad del sistema.
    Diagnóstico / DB Manager Diagnóstico muestra el estado del sistema; DB Manager permite ejecutar SQL con permisos elevados.

    Términos técnicos y formatos¶

    Término Definición
    CSV / PDF / JSON / XML / SQL Formatos de intercambio, informe, datos y consulta usados por la aplicación.
    HTML / URL / URI Lenguaje de marcado, localizador y identificador de recursos.
    PHP-FPM / Apache / MySQL / Percona Componentes habituales del servidor web y de base de datos.
    EL9 / EL10 / Ubuntu Sistemas operativos soportados para la instalación.
    MB / GB Unidades de tamaño de fichero y almacenamiento.

    Términos ambiguos¶

    Forma problemática Forma recomendada
    compañía empresa
    workunit unidad de trabajo (el identificador workunit se cita como código)
    KB base de conocimiento
    ticket / incidencia ticket para el objeto; «incidencia» como concepto general
    usuario / contacto usuario con acceso; contacto sin acceso
    perfil / rol perfil concede permisos; rol matiza funciones
    grupo / equipo grupo controla visibilidad; equipo reparte tickets
    consola interfaz
    SLA / ANS SLA, desarrollado la primera vez
    PandoraFMS Pandora FMS
    Office 365 Microsoft 365
    LTS / FR / OUM / MR Desarrollar cada sigla en su primera aparición
